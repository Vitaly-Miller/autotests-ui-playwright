# Ввод данных в Playwright

---
### `.fill()` 
- МГНОВЕННАЯ вставка текста
- ℹ️ Автоматически очищает поле перед вставкой.


```python
locator.fill('text')               # мнговенная вставка тескта
locator.fill('text', force=True)   # элемент перекрыт другим слоем
```


---

### `.type()` ⚠️
 - ПОСИМВОЛЬНАЯ вставка текста (эмуляция в один цикл)
- ⚠️ Помечен как устаревший в пользу `.press_sequentially()`
- ℹ️ **Не очищает поле** — печатает поверх текущего значения (очищай через `.fill('')` или `.clear()`)

```python
locator.type('text')              # посимвольный вставка текста без задержки
locator.type('text', delay=50)    # посимвольный вставка текста с задержкой 50 ms
```

---

### `.press_sequentially()`
- ПОСИМВОЛЬНАЯ вставка текста (**реальная эмуляция**)
- ℹ️ Для каждого символа эмулирует полный цикл событий: `keydown` → `keypress` → `input` → `keyup`.
- ℹ️  **Не очищает поле** — печатает поверх текущего значения (очищай через `.fill('')` или `.clear()`)

```python
locator.press_sequentially('text')             # посимвольный вставка текста без задержки
locator.press_sequentially('text', delay=50)   # посимвольный вставка текста с задержкой 50 ms
```

**Когда использовать:** нужно протестировать реальное поведение при посимвольном вводе (счётчик символов, live-подсказка, маска телефона, автокомплит)
